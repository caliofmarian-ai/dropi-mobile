# DROPi — Project Transfer

## 1. Scop

Document de transfer rapid pentru orice agent/developer nou, fără pierdere de context.

## 2. Ce trebuie citit primul

1. `canonical/SESSION_HANDOVER.md`
2. `canonical/AI_DEVELOPMENT_HANDOVER_CANON.md`
3. `ARCHITECTURE.md`
4. `DEPLOYMENT.md`
5. `ROADMAP.md`

## 3. Context de transfer (actual)

- Platformă: React Native + Expo + backend Node.js/tRPC.
- Flux real de validare mobilă: telefon + Expo Dev Client + backend cloud.
- Build/update mobil prin EAS + GitHub Actions.
- `main` este branch protejat: promovare prin PR.

## 4. Surse canonice extinse

În repository există și arhiva `04.zip`, care conține setul extins de documente canonice istorice (`04/DROPI_CANONICAL/*`), inclusiv masterplanul pe capitole.

## 5. Reguli de handover

- La finalul sesiunii: actualizare obligatorie `canonical/SESSION_HANDOVER.md`.
- Continuarea unei sesiuni noi se face din „Pasul Următor Concret”.
