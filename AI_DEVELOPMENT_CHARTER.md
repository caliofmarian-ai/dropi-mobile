# DROPi — AI Development Charter

## 1. Scop

Acest charter stabilește regulile de colaborare om + AI pentru dezvoltarea DROPi, în continuitate cu documentele canonice existente.

## 2. Principii

1. **Continuitate fără restart**: fiecare sesiune pornește din starea documentată.
2. **Sursă de adevăr duală**:
   - Repository pentru implementare.
   - Documentele canonice pentru viziune, guvernanță și direcție.
3. **Documentare continuă**: ideile și deciziile se actualizează în documentație.
4. **Audit înainte de implementări majore**.
5. **Siguranță operațională**: fără vulnerabilități și fără secrete expuse.

## 3. Proces canonic de lucru

Pentru taskuri majore:
1. Observe
2. Analyse
3. Plan
4. Implement
5. Test
6. Document

## 4. Criterii de calitate

- Schimbări minimale și corecte.
- Trasabilitate decizii.
- Aliniere cu fluxul mobile-first (telefon + Expo Dev Client + backend cloud).
- Respectarea regulilor de release și handover.
